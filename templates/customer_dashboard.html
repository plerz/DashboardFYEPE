Viewer Demographics

Age · Gender · Location

Data penonton organik per usia, gender, dan lokasi tidak tersedia melalui API TikTok yang saat ini terhubung ke DashFYEPE. Jangan mengisi angka perkiraan di sini agar laporan customer tidak menyesatkan.
Untuk data iklan, TikTok memiliki API komersial tertentu, tetapi itu bukan endpoint untuk mengambil demografi penonton organik dari posting biasa. Akses dan cakupannya juga bergantung pada produk/kelayakan TikTok.
Penting soal “Views dari jaringan kita vs di luar”. Angka Views pada tabel adalah total views postingan. Karena TikTok tidak memberikan identitas/asal setiap penonton melalui video.list, DashFYEPE tidak boleh menyebut misalnya “8 juta views berasal dari 1.000 akun kita” kecuali TikTok menyediakan data tersebut secara resmi. Yang dapat dipastikan saat ini adalah siapa pemilik postingan (akun jaringan kita) dan berapa total engagement postingannya.
